# Симулятор аэропорта

Консольная игра на C# и .NET 10, моделирующая работу аэропорта. Рейсы прибывают по расписанию, занимают взлётно-посадочные полосы и гейты, проходят обслуживание и отправляются дальше.

## Запуск

```powershell
dotnet run --project src/AirportSimulator.Console
```

Графический веб-интерфейс:

```powershell
dotnet run --project src/AirportSimulator.Web
```

В панели управления доступны запуск и пауза симуляции, ручные шаги времени, сброс сценария, табло рейсов, состояние полос и гейтов, погода, показатели и журнал событий.

Команды: `step [минуты]`, `run [минуты]`, `status`, `flights`, `weather`, `report`, `events`, `help`, `exit`.

Погода меняется каждые 30 виртуальных минут. Дождь и туман замедляют операции, а во время шторма новые посадки и взлёты приостанавливаются. Генератор использует фиксированное начальное значение, поэтому сценарий воспроизводим.

## Проверка

```powershell
dotnet test
```

## Архитектура

- `AirportSimulator.Domain` — аэропорт, рейсы, самолёты, полосы и гейты;
- `AirportSimulator.Application` — виртуальное время и движок симуляции;
- `AirportSimulator.Console` — первая игровая оболочка;
- `AirportSimulator.Web` — интерактивная панель управления на Blazor;
- `AirportSimulator.Tests` — автоматические проверки правил.

Следующие этапы: погода, случайные происшествия, финансы, сохранения и графический интерфейс.
